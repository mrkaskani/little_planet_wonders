# 2. Why it matters for children under five

A master creative prompt is not one enormous prompt used unchanged for every task. It is a structured template that selects the relevant permanent and current context for a specific output.

A strong prompt tells the creator or model what the task is, who and what must remain consistent, what the current story state is, what one main action should occur, how the camera and emotion behave, what safety limits apply, and how the result will be reviewed.

For children under five, the prompt must also preserve clarity, comfortable motion, simple composition, readable emotion, and safe imitation.

# 3. Core concepts

## 1. Audience and purpose

State who the output serves and why it is being created. This affects language, visual density, motion, and emotional intensity.

## 2. Permanent identity

Include only relevant character, location, visual, audio, and safety rules.

## 3. Current state

Describe the episode, scene, shot, and temporary conditions that affect this task.

## 4. Primary action

Use one clear action or output goal. Avoid combining several story beats.

## 5. Starting state

Define the exact visible or audible condition before the change.

## 6. Ending state

Define the intended result. A clear ending state helps prevent incomplete action.

## 7. Camera

Specify shot size, height, screen direction, and one camera behavior when visual media is involved.

## 8. Emotion

Define readable emotion and maximum intensity. Emotion should match story scale.

## 9. Change and unchanged lists

Separate allowed modifications from protected identity, wardrobe, location, props, camera, lighting, and safety.

## 10. Child-safety constraints

Include only task-relevant safety rules plus the permanent requirement for human review.

## 11. Output requirements

Define the exact artifact: one image, reference sheet, first frame, last frame, dialogue line, speaking clip, or review report.

## 12. Review criteria

State what must pass: identity, action, prop, emotion, lighting, safety, beginning, ending, and small-screen clarity.

## 13. Prompt economy

Use enough detail to control the output, but remove unrelated history and duplicated instructions.

# 6. Reusable prompt template

Using the Context-Layer Map, create one task-specific master creative prompt.

Include:
- audience and purpose;
- relevant permanent context;
- episode, scene, shot, and segment context;
- exact starting and ending states;
- one primary action;
- camera, lighting, color, emotion, timing, or performance as relevant;
- allowed changes;
- unchanged elements;
- child-safety constraints;
- exact output requirements;
- review criteria.

Remove:
- unrelated project history;
- duplicated instructions;
- contradictory adjectives;
- several actions in one segment;
- vague words without practical meaning.

**Output requirements**  
Produce one clean prompt and a short explanation of why each section is necessary.

# 7. Weak prompt

> Make a beautiful, cinematic, cute, exciting scene where Lumi does lots of things with the ball and keep everything consistent.

---

# 8. Diagnosis of the weak prompt

- The output type is unclear.
- “Beautiful,” “cinematic,” and “exciting” are undefined.
- Several actions are implied.
- Starting and ending states are missing.
- Consistency is requested but not specified.
- Camera, emotion, safety, and review criteria are absent.
- The prompt does not identify what may change.

---

# 9. Improved prompt

Create one first-frame image for a preschool color-learning shot.

Use Lumi’s approved identity and the approved Rainbow Garden reference. Lumi stands left of the red fabric ball on the central path. She has just noticed it.

Use an eye-level medium-wide composition with a locked-camera perspective, soft warm daylight, simple background, and gentle curiosity.

Allow only Lumi’s eye direction and small head turn to change. Keep her face, hair, coral overalls, cream shirt, yellow boots, proportions, ball identity, path, gate, baskets, lighting, and camera unchanged.

Output one frame with clear ball visibility, safe posture, readable expression, and no extra objects or characters.

---

# 12. Common mistakes

1. Using the same full prompt for every task.
2. Adding vague style adjectives.
3. Combining several actions.
4. Failing to define ending state.
5. Writing “keep consistent” without a list.
6. Duplicating permanent context several times.
7. Leaving output size or type undefined.
8. Forgetting review criteria.

---

# 13. Fifteen-minute practical exercise

Create three master prompts:

1. One character reference image.
2. One first-frame image.
3. One exact dialogue review task.

For each:
- import only relevant permanent context;
- add current production context;
- define start, end, and one action;
- define change and unchanged lists;
- add safety;
- define output and review criteria.

Then remove any repeated or irrelevant information.

# 15. Short quiz and answers

### Question 1

Is a master prompt one fixed prompt for everything?

### Answer

No. It is a structured template filled with relevant context.
### Question 2

Why define starting and ending state?

### Answer

To control the intended change and action completeness.
### Question 3

What does “keep consistent” need?

### Answer

An explicit list of protected elements.
### Question 4

How many primary actions should a segment prompt contain?

### Answer

One.
### Question 5

Why include review criteria?

### Answer

To define approval before generation.
