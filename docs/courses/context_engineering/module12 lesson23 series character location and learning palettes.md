# 1. Learning objective

- Build a controlled series color system.
- Separate identity colors from temporary story color.
- Use learning colors clearly without relying only on color.
- Create a Color Bible.

---

# 2. Why it matters for children under five

Color helps children recognize characters, locations, objects, emotions, and learning concepts. It can also create confusion when too many saturated colors compete or when the same color changes meaning from one episode to another.

A Color Bible organizes color into layers. The series has a core palette. Each character and location has a stable identity palette. Learning objects may receive stronger emphasis. Emotional scenes may shift the surrounding palette without changing character identity.

Color should never be the only way essential information is communicated. A red basket may also have a circle symbol, spoken label, and stable position.

# 3. Core concepts

## 1. Series palette

The limited family of colors that gives the entire project a recognizable identity.

## 2. Character palette

Stable colors associated with each character. These should remain distinct from common location backgrounds.

## 3. Location palette

Recurring dominant and accent colors that help identify a place.

## 4. Learning color

A color intentionally emphasized because it is the lesson. Other colors should be controlled so the target color is easy to find.

## 5. Saturation hierarchy

Do not make every color equally bright. Reserve stronger saturation for important objects, actions, or joyful moments.

## 6. Value contrast

Light-dark contrast helps object separation. Children should still be able to find the ball if the image is viewed in reduced color.

## 7. Color continuity

Track palette changes across connected shots. Character clothing, prop color, weather color, and light temperature must remain stable unless a change is shown.

## 8. Emotional color support

Color may gently support emotion, but should not turn mild concern into danger through dark red, black, or harsh contrast.

## 9. Accessibility beyond color

Use shapes, symbols, spoken labels, position, and object differences so essential meaning is not dependent only on color vision.

## 10. Output control

Record approximate color names and relationships rather than allowing every prompt to invent new hues.

# 4. Practical example from the ongoing series

## Red-learning scene

- The red ball uses warm clear red.
- The red basket uses the same family of red.
- The blue basket uses a softer blue.

# 7. Weak prompt

> Use every bright color everywhere so the episode feels fun and educational.

---

# 8. Diagnosis of the weak prompt

- All colors compete for attention.
- The learning color loses emphasis.
- High saturation may overstimulate.
- Character and location identity become weak.
- No continuity or accessibility rules are included.
- “Fun” is being reduced to brightness.

---

# 9. Improved prompt

Use the approved warm series palette. Emphasize the red learning objects with clear value separation and open space. Keep nearby flowers and backgrounds muted.

Preserve Lumi’s coral overalls, Pip’s teal body, Auntie Noura’s sage apron, and the Rainbow Garden’s yellow gate and blue watering station. Use shape symbols and spoken labels in addition to color.

Avoid full-frame high saturation, random hue changes, neon colors, and equal emphasis across all objects.

# 12. Common mistakes

1. Using maximum saturation everywhere.
2. Changing identity colors for mood.
3. Making target color similar to the background.
4. Depending only on color for choices.
5. Using lighting to shift a prop into another apparent color.
6. Ignoring value contrast.
7. Failing to track color across edits.

---

# 13. Fifteen-minute practical exercise

Create a Color Bible.

1. Choose the series primary, secondary, and neutral palette.
2. Define each main character’s palette.
3. Define three location palettes.
4. Define learning-color emphasis.
5. Set saturation and value rules.
6. Add non-color support.
7. Review a red-learning frame and simplify competing color.
8. Define connected-shot continuity checks.

# 15. Short quiz and answers

### Question 1

What is saturation hierarchy?

### Answer

The planned use of stronger and weaker color intensity.
### Question 2

Why define character palettes?

### Answer

To support recognition and continuity.
### Question 3

Can mood change character identity colors?

### Answer

Normally no.
### Question 4

Why add symbols or labels?

### Answer

Essential information should not depend only on color.
### Question 5

What else besides hue supports readability?

### Answer

Value, shape, spacing, position, and spoken language.
