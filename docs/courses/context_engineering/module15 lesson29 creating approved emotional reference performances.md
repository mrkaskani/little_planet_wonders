# 2. Why it matters for children under five

An emotional voice reference is a short approved performance showing how a character sounds in a particular emotional state. It helps preserve identity and delivery style.

A reference is not the final dialogue for an episode. It provides style, not exact words or timing. The final speaking shot must still use exact approved dialogue audio.

Reference performances should be clean, short, consistent, and emotionally controlled. They should avoid music, ambience, sound effects, multiple voices, and exaggerated acting.

# 3. Core concepts

## 1. Purpose of a reference

A reference demonstrates identity, pitch, warmth, pace, articulation, and emotional delivery.

## 2. Reference versus final line

The reference teaches style. The final line determines exact words, timing, pauses, breathing, emotion, duration, and lip synchronization.

## 3. Reference set

Create neutral-friendly, happy-gentle, curious, mild concern, reassuring, and optional singing or bedtime narration references.

## 4. Reference script design

Use short lines that naturally express the emotion and contain useful sounds. Avoid episode-specific facts that may become confusing later.

## 5. Clean audio

Use one voice only, no music, effects, room noise, or background conversation.

## 6. Performance consistency

All references should preserve vocal age, accent, pronunciation, pitch range, and character identity.

## 7. Emotional separation

Each reference should be clearly distinguishable without extreme acting.

## 8. Duration

Keep references long enough to reveal the voice but short enough to remain controlled and easy to compare.

## 9. Approval process

Review every reference for missing words, noise, unstable identity, overacting, and child comfort. Approve and lock only the strongest take.

## 10. Reference naming and tracking

Use clear names such as Lumi_neutral_friendly_reference and record approval status and notes.

# 6. Reusable prompt template

Create an Emotional Voice Reference Plan for [CHARACTER].

Use the approved Character Voice Bible.

Create reference scripts and direction for:
- neutral-friendly;
- happy-gentle;
- curious;
- mild concern;
- reassuring;
- optional singing;
- optional bedtime narration.

For each reference:
- preserve character identity;
- use a short self-contained line;
- define pitch, pace, warmth, energy, and volume;
- avoid episode-specific final dialogue;
- avoid extreme emotion;
- define review criteria.

**Audio cleanliness requirements**  
One voice only. No music, ambience, Foley, effects, or other speakers.

**Output requirements**  
Produce a reviewable reference plan, approval fields, and locked-reference naming convention.

---

# 7. Weak prompt

> Use one random emotional clip from any episode as the reference for every future line.

---

# 8. Diagnosis of the weak prompt

- A random clip may contain mixed audio.
- The line may not represent neutral identity.
- One emotion cannot guide every delivery.
- Episode timing and performance may be unsuitable as a reusable reference.
- Identity may drift if references are inconsistent.
- No approval or locking process is defined.

---

# 9. Improved prompt

Create separate approved references for Lumi’s neutral-friendly, happy-gentle, curious, mild concern, and reassuring delivery.

Use clean, short, self-contained lines recorded with one voice only. Preserve the same vocal age, accent, pronunciation, warmth, and core pitch range. Change only the emotional delivery within approved limits.

Review several candidates, select the strongest performance for each emotion, and lock the approved reference. Do not use a mixed episode clip or final dialogue as the only reference.

---

# 12. Common mistakes

1. Using one reference for every emotion.
2. Using a noisy episode clip.
3. Adding music to the reference.
4. Making the reference too long.
5. Using extreme emotional acting.
6. Changing accent or vocal age.
7. Failing to lock approved versions.

---

# 13. Fifteen-minute practical exercise

Create an Emotional Voice Reference Plan for one character.

1. Write five short scripts.
2. Add performance direction for each.
3. Define identity features that stay unchanged.
4. Add cleanliness rules.
5. Create a candidate-review checklist.
6. Define file naming and approval status.
7. Compare the emotional set for consistency.

# 15. Short quiz and answers

### Question 1

What does an emotional reference preserve?

### Answer

Voice identity and delivery style.
### Question 2

Does it replace exact final dialogue?

### Answer

No.
### Question 3

Why use separate emotions?

### Answer

Different emotional deliveries need controlled examples.
### Question 4

What should reference audio contain?

### Answer

One clean voice only.
### Question 5

What happens after approval?

### Answer

The reference is locked and reused consistently.
